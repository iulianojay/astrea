
## Roadmap

Right now, I'm still a solo dev so there's no strict roadmap, but here are some of the features I plan to implement in the future:

- **Environmental Models**: High-fidelity atmospheric and solar models
- **Semi-analytical and Specialized Propagators**: SGP4/SGP8 and specialized cislunar dynamics (BC4BP)
- **Mission Planning**: Trajectory optimization and automated scheduling tools
- **Extended Element Sets**: Additional orbital representations and optimized transformations, including mean element sets
- **Validation**: Real-world comparisons using GPS and tracking data
- **Visualization**: GUI interface for analysis and mission visualization

Feel free to check out the [issues page](https://github.com/iulianojay/astrea/issues) for a list of planned features and to contribute ideas or suggestions.
