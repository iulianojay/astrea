# About Astrea

## The Story Behind Astrea

**Astrea** is named after the Greek goddess of precision, Astraea. 

Developed by a single maintainer, the project emerged from a simple frustration: the lack of easy-to-use, extensible, modern C++ libraries for astrodynamics programming. While the aerospace industry has produced incredible feats of engineering, the software tools available to aerospace engineers often lag decades behind modern programming practices. Legacy FORTRAN codes, proprietary tools with restrictive licenses, and academic projects that prioritize research over usability have left a significant gap in the ecosystem.

Astrea represents an attempt to bridge this gap—combining decades of aerospace engineering knowledge with modern software engineering practices to create something both powerful and pleasant to use.

## Why Astrea Exists

### The Problem
The astrodynamics software landscape has been dominated by:

- **Legacy Systems**: FORTRAN codes from the 1970s that are difficult to integrate and maintain
- **Proprietary Tools**: Expensive commercial software with restrictive licensing
- **Academic Projects**: Research-focused libraries that prioritize novel algorithms over usability
- **Language Barriers**: Many modern tools written in Python or MATLAB, limiting performance

### The Solution
Astrea addresses these challenges by providing:

- **Modern C++**: Leveraging C++23 for both performance and developer experience
- **Open Licensing**: LGPL ensures both academic freedom and commercial applicability
- **Production Quality**: Designed for real-world use, not just research prototypes
- **Community Driven**: Open development model encouraging contributions and feedback


## Development Journey

### Origins
Astrea began as a personal passion project in 2023, driven by the need for better tools in astrodynamics research. What started as a small collection of orbital mechanics utilities gradually evolved into a comprehensive library as the scope of aerospace engineering applications became clear.

### Development Philosophy
While primarily developed by a single maintainer, Astrea incorporates lessons learned from:
- **Industry Experience**: Best practices from aerospace and software engineering
- **Academic Research**: Cutting-edge algorithms and validation methodologies  
- **Open Source Community**: Development practices from successful C++ projects
- **User Feedback**: Real-world usage in research and educational settings

### Evolution
The library has evolved through several phases:
1. **Foundation** (2023): Basic orbital mechanics and coordinate transformations
2. **Integration** (2024): SPICE integration, time systems, and data management
3. **Analysis** (2025): Access analysis, link budgets, and mission planning tools
4. **Maturation** (2026): Professional documentation, packaging, and community building

### Current Status
Astrea is actively used in:
- **Academic Research**: Graduate programs and aerospace engineering coursework
- **Small Projects**: Personal and startup aerospace ventures
- **Open Source Tools**: As a backend for other space-related software

## Recognition and Gratitude

Astrea exists because of the foundational work of countless aerospace engineers, mathematicians, and software developers who have advanced the field over the past century. The algorithms, mathematical formulations, and computational techniques embedded in Astrea represent the collective knowledge of generations of researchers and practitioners.

### Key Dependencies and Inspiration
Astrea is built upon exceptional open-source projects:
- **[mp-units](https://github.com/mpusz/mp-units)**: Providing the foundation for safe, compile-time unit checking
- **[SPICE Toolkit](https://naif.jpl.nasa.gov/naif/toolkit.html)**: NASA's planetary and spacecraft geometry system
- **[Orekit](https://www.orekit.org/)**: The Java space dynamics library that proved astrodynamics libraries could be both powerful and accessible
