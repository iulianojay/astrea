# Welcome to **Astrea**

**Astrea** is a C++ astrodynamics library meant as an extensible baseline for mission-design tools, analysis, and other aerospace applications. The core of Astrea is a strongly-typed, unit-aware, and frame-aware type system that provides a foundation for building safe and efficient astrodynamics software. The library also includes a growing collection of algorithms and utilities for common astrodynamics tasks, such as orbit propagation, maneuver planning, and coordinate transformations. Astrea is designed to be modular and extensible, allowing users to easily add new functionality and customize the library to their specific needs. 

Astrea is open-source and available on GitHub. We welcome contributions from the community, whether it's bug fixes, new features, or documentation improvements. If you're interested in contributing, please check out our [contributing guidelines](getting_started/contributing.md) and feel free to reach out to us with any questions, issues, or ideas.
