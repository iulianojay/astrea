    function get_position_at¶

    template<auto _body_>
inline constexpr  CartesianVector < Distance , get_parent_frame( _body_ , axes::icrf )> astrea::astro::get_position_at (
    const  Date & date
)

    Primary template declarations for ephemeris position/velocity (NTTP-based). Explicit specialisations are provided in planet headers (Chebyshev ephemeris). The primary template definition (Keplerian fallback) is provided by default_property_getters.hpp, which celestial_bodies.hpp includes after all planet headers.

    Used for bodies that have orbital element parameters but no Chebyshev ephemeris specialisation (e.g. Phobos, Deimos, small moons). The result is expressed in the parent-body ICRF frame derived from the body's parent origin.

    Bodies WITH an explicit get_position_at specialisation (e.g. Earth, Jupiter when ephemeris is enabled) use that specialisation in preference to this primary template.
