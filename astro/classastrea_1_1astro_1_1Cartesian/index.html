    Detailed Description¶

    This class encapsulates the position and velocity of a vehicle in Cartesian coordinates.

    function in_frame [1/2]¶

    Converts this Cartesian state to an equivalentCartesian state in a different frame. 

    template<IsFrame auto target_frame>
inline Cartesian < target_frame > astrea::astro::Cartesian::in_frame (
    const Date & epoch
) const

    Uses proper physical frame transformation (translation and rotation) via in_frame on each component vector. The gravitational parameter is accepted but not used; it exists so that Cartesian shares a uniform in_frame(epoch, mu) signature with Keplerian and Equinoctial.

    Template parameters:

    • target_frame The target frame.

    Parameters:

    • epoch The epoch at which to evaluate the frame transformation.

    Returns:

    Cartesian<target_frame> This state expressed in the target frame.
